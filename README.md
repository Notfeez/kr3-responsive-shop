# kr3-responsive-shop

## Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание проекта

Многостраничный учебный интернет-магазин «VacuumShop», перенесённый из КР №1 и адаптированный под экраны от 360 px до 1440 px. Bootstrap не используется. Адаптивность реализована в файле `css/responsive.css` по подходу Mobile First. Доступность улучшена по результатам аудита и проверена через Lighthouse.

## Подключение CSS

На каждой странице два файла подключены в таком порядке:

```html
<link rel="stylesheet" href="css/style.css">
<link rel="stylesheet" href="css/responsive.css">
```

`responsive.css` идёт после `style.css`, поэтому адаптивные правила его переопределяют.

## Адаптивные решения

- Подход Mobile First: базовые правила для узких экранов, расширения через `min-width`.
- Точки перелома: 480 px (крупные телефоны), 768 px (планшет), 1024 px (десктоп).
- Viewport `width=device-width, initial-scale=1.0` на всех страницах.
- Шапка и навигация: пункты меню переносятся на новую строку, на телефоне имеют высоту не менее 44 px.
- Hero-блок: меньшие отступы и размер заголовка на телефоне, увеличение с 480 и 768 px.
- Сетка карточек товаров (Grid): 1 колонка на телефоне, 2 с 480 px, 3 с 1024 px.
- Сетка категорий на главной (Grid): 1, 2 и 4 колонки по тем же точкам.
- Каталог (Flexbox и Grid): фильтр над списком на телефоне, слева от списка с 1024 px, с прилипанием при прокрутке.
- Страница товара (Flexbox и Grid): фото и описание друг под другом, рядом с 768 px.
- Изображения: `max-width: 100%; height: auto;`. Карточки и категории используют `srcset` с `sizes` и `loading="lazy"`.
- Форма заявки: одна колонка на телефоне, две с 768 px. Кнопки на всю ширину на телефоне.
- Таблица характеристик обёрнута в `.table-wrapper` с `overflow-x: auto`. Широкая таблица прокручивается внутри своего блока, а не всей страницы.
- Модальное окно ограничено шириной экрана и прокручивается при нехватке места.

## Исправления, внесённые относительно КР №1

- На страницах товара `</body>` стоял до модального окна, а блок `.product-detail` не был закрыт. Структура исправлена.
- На страницах товара в кнопке заказа было указано «Товар 3». Теперь там название товара.
- На каталоге и контактах не было элементов, которых ждал `main.js`, поэтому скрипт падал с ошибкой. В `main.js` добавлены проверки на наличие элементов.
- Страница `order.html` добавлена отдельно, потому что методичка её требует.
- В контакты добавлена форма обратной связи.
- В `style.css` сетка категорий задана классом `.categ.categories-grid`, а в HTML используется `.categories-grid`. Стиль для него задан в `responsive.css`. Сам `style.css` не менялся.
- Добавлены skip-link, `id="main"` у `<main>` и видимый фокус.

## Доступность

- Skip-link «Перейти к основному содержимому» на всех страницах.
- Видимый фокус (`:focus-visible`, контур 3 px) на всех интерактивных элементах.
- У всех полей формы есть `label`. У изображений есть `alt`.
- На каждой странице один `h1`. Заголовки идут по порядку.
- Навигация размечена через `<nav aria-label>`, текущая страница отмечена `aria-current="page"`.
- Таблица имеет `caption`, заголовки столбцов и строк (`th scope`).
- Сообщения об успехе имеют `role="status"` и получают фокус при появлении.
- Учитывается `prefers-reduced-motion`.

## Изображения

Изображения взяты из репозитория КР №1 (`cleaner1–3.jpg`, `corded.jpg`, `windows.jpg`). Для каждого используются варианты `-480.jpg` и `-960.jpg` в `srcset`; они уже созданы. Чтобы пересоздать их после замены исходников:

```bash
bash scripts/make-variants.sh
```

Скрипт требует ImageMagick. Он уменьшает только большие файлы и не увеличивает маленькие.

Временные замены на главной: в КР №1 ссылались на файлы `cat-corded.jpg`, `cat-robot.jpg` и `cat-window.jpg`, которых нет в репозитории. Вместо них сейчас стоят `cleaner1.jpg` (Corded), `cleaner2.jpg` (Robot vacuum cleaner) и `windows.jpg` (Cleaners for windows). Лучше заменить на свои фото этих категорий.

| Ширина | Устройство | Проверено |

| 1024 px | Небольшой десктоп | ☐ |
| 1440 px | Широкий десктоп | ☐ |

На каждой ширине проверить: шапку, навигацию, hero, сетку карточек, каталог с фильтром, страницу товара, таблицу, форму заявки, контакты, подвал и модальное окно. Горизонтальной прокрутки всей страницы быть не должно.
